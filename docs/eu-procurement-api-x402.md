# EU Procurement API for Agents and Developers

Revenue Swarm exposes live EU public-procurement opportunity data through small pay-per-request x402 endpoints on Base USDC.

## Live endpoints

- `GET https://eu-tender-x402-v3-production.up.railway.app/api/tender-pulse` — 0.001 USDC
- `GET https://eu-tender-x402-v3-production.up.railway.app/api/tenders` — 0.01 USDC
- `GET https://eu-tender-x402-v3-production.up.railway.app/api/tender-intelligence` — 0.10 USDC

The service is intended for supplier discovery, procurement research, business-development workflows and software agents that need ranked tender opportunities with buyer, deadline and official source evidence.
