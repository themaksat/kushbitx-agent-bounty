## One-line pitch

A newcomer-friendly visual that explains RustChain's Proof-of-Antiquity loop: install the miner, prove real physical hardware with fingerprint checks, then receive a vote weight based on hardware antiquity while VMs/emulators are penalized.

## Coverage checklist

- 1 CPU = 1 vote, weighted by hardware antiquity.
- Fingerprint / anti-emulation idea: real hardware vs VM farms.
- Where to start: `pip install clawrtc`.
- Why it matters: hardware diversity and harder-to-fake physical participation.
